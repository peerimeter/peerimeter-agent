Install the WireGuard agent

Linux · macOS · Windows

Latest release: v0.1.0. The installer verifies release checksums before installing.

Linux

Install the latest release to a custom directory:

curl -fsSL https://agent.peerimeter.app/install.sh | sh -s -- --install-dir "$HOME/.local/bin"

For a system-wide install, choose a version and destination:

curl -fsSL https://agent.peerimeter.app/install.sh | sudo sh -s -- --version v0.1.0 --install-dir /usr/local/bin

macOS

Install the latest release to a custom directory:

curl -fsSL https://agent.peerimeter.app/install.sh | sh -s -- --install-dir "$HOME/.local/bin"

For a system-wide install, choose a version and destination:

curl -fsSL https://agent.peerimeter.app/install.sh | sudo sh -s -- --version v0.1.0 --install-dir /usr/local/bin

Windows PowerShell

Open PowerShell as Administrator. Install with the defaults:

irm https://agent.peerimeter.app/install.ps1 | iex

Or pass a version and destination in a one-liner:

& ([scriptblock]::Create((irm 'https://agent.peerimeter.app/install.ps1'))) -Version v0.1.0 -InstallDir 'C:\Tools\Peerimeter'

If you downloaded the script, run .\install.ps1 -Version v0.1.0 -InstallDir 'C:\Tools\Peerimeter'.

What the installer does

It downloads the matching release package, verifies its SHA-256 checksum, installs program files and registers an installation inventory. It does not enroll the agent or change your configuration and keys.

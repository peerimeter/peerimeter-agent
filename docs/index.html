Install the WireGuard agent

Linux · macOS · Windows

Latest release: v0.1.0. The installer verifies release checksums before installing.

Linux and macOS

Install the latest release to a custom directory. For per-user installs, add $HOME/.local/bin to PATH:

curl -fsSL https://agent.peerimeter.app/install.sh | sh -s -- --install-dir "$HOME/.local/bin"

For a system-wide install, choose a version and destination:

curl -fsSL https://agent.peerimeter.app/install.sh | sudo sh -s -- --version v0.1.0 --install-dir /usr/local/bin

Windows PowerShell

Open PowerShell as Administrator. Install with the defaults:

irm https://agent.peerimeter.app/install.ps1 | iex

Or pass a version and destination in a one-liner:

& ([scriptblock]::Create((irm 'https://agent.peerimeter.app/install.ps1'))) -Version v0.1.0 -InstallDir 'C:\Tools\Peerimeter'

If you downloaded the script, run .\install.ps1 -Version v0.1.0 -InstallDir 'C:\Tools\Peerimeter'.

Use the agent CLI

Run peerimeter-agent <command> --help for options, or open the CLI reference. On Linux and macOS, use sudo for tunnel and service commands; on Windows, use an elevated PowerShell window. For per-user installs, add $HOME/.local/bin to PATH. Since sudo may use a different PATH, use the full executable path for elevated commands. Generate keys as the same user that runs the agent.

CommandDescription
generate-exampleCreate sample mesh configs and keys
validate-configValidate a config and its private key
run / daemonRun the tunnel, optionally syncing periodically
join / syncEnroll in a managed network and refresh peers
status / wgShow local tunnel and peer status
stopStop the tunnel and clean up routes
service <install|start|stop|migrate|uninstall>Manage the native OS service
uninstall / self-updateRemove an installation or update it
stun / info / versionProbe UDP mapping or show agent information

System install example: sudo /usr/local/bin/peerimeter-agent run --config /path/to/peer.yaml (Linux/macOS); peerimeter-agent.exe run --config C:\path\to\peer.yaml (elevated PowerShell). run stays in the foreground. Static configurations use reachable endpoints for separate devices; STUN reports an observed address but does not guarantee NAT traversal. See the examples guide and detailed agent guide.

What the installer does

It downloads the matching release package, verifies its SHA-256 checksum, installs program files and registers an installation inventory. It does not enroll the agent or change your configuration and keys.
